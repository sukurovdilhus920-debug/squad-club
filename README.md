# SQUAD CLUB — сайт киберклуба

Одностраничный сайт киберспортивного клуба Esports Squad Club (Красногорск, Строительная улица, 3А).

- `index.html` — весь сайт: разметка, стили и скрипты в одном файле, без сборки.
- `assets/` — видео первого экрана (4K / 1080p / 720p), фото зала, карта, логотип.
- `assets/games/` — обложки игр, `assets/trailers/` — короткие трейлеры для библиотеки игр.

Видео первого экрана — Pexels (бесплатная лицензия). Обложки и трейлеры игр принадлежат их издателям.
